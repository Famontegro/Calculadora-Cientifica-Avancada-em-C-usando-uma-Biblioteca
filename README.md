# 🧮 Calculadora Científica em C

Uma calculadora científica avançada em C com formulas, com utilidade em usa-la como um projeto de estudo durante meu curso de Engenharia da Computação.

## ⚙️ Aplicativos utilizados:

No inicio do projeto, eu utilizei o Dev-C++ 4.9.9.2, porem ao decorrer do tempo, o código começou a ficar muito extenso, e já que no Dev-C++ mas não para minimizar certas funções do programa, eu migrei para o VS Code.

## 📌 Sobre o projeto

> Meu nome é Rafael Montenegro, no momento em que fiz esse programa estou estudando Engenharia da Computação no segundo semestre na USF, e este é meu primeiro projeto grande em C!!! 

Ainda estou aprendendo a linguagem, portanto, ao decorrer do codigo você pode notar coisas como eu mudando a maneira de escrever, o codigo não ser tão bonito e talvez até erros. 
Ela consiste em uma calculadora científica desenvolvida inteiramente em linguagem C com formulas matematicas, fisicas, e mais. 
Eu montei esse desafio para mim mesmo, ele é, utilizar somente uma biblioteca, eu podia ter utilizado a 'math.h' mas seria tanto quanto sem graça, então eu utilizei somente a 'stdio.h'. 
Fiz essa calculadora para praticar os conceitos fundamentais da programação, tanto porque essa é a primeira linguagem de programação que eu aprendo, porém eu não sabia que ia ficar tão grande, ao decorrer do programa, eu fui mudando os objetivos dessa calculadora, por isso ela possui 3069 linhas de código com 44 menus e 107 operações diferentes.
